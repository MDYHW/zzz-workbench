# Sigrid Vertical Requirements

## Summary

Add Sigrid and Knight's Extolment through the current Agent-centered setup and
source-owned equipment flows. Preserve Sigrid's completed-Core CRIT direction,
Stunned-enemy outcome, Converging Spear action differences, qualifying flat ATK,
and current Mindscape deltas without adding a Contamination target state, raw
damage, rotation, block-cadence, or Heavy-Attack capability model.

## Product Flows

1. Applying Sigrid prepares one complete M0 setup for the selected W-Engine
   availability pool with zero supplied substats. Full starts on Knight's
   Extolment; non-limited starts on The Brimstone. Both start on Dawn's Bloom
   4-piece, Puffer Electro 2-piece, and CRIT DMG / PEN Ratio / ATK% mains.
2. Users may edit the bounded competitive W-Engine, Disc, main-stat, and
   effective-substat choices. Dialyn's received-Ultimate operation adds Puffer
   Electro 4-piece as a contextual Sigrid candidate without rerunning preparation.
3. Result shows Sigrid's completed-Core, Basic, Chain, Additional Ability,
   Mindscape, and selected-equipment outcomes at their exact retained actions
   and surfaces. Setup keeps the complete compressed selected equipment package
   even when a clause has no Result consumer.
4. Material broad pre-PEN pressure removes Puffer Electro 2-piece and PEN Ratio
   Slot 5. Authorized preparation uses Polar Metal and Ice DMG; a direct edit
   clears only newly invalid selections and chooses no fallback.

## Requirements

### Source and identity

- R1. Admit Sigrid as an S-Rank Ice Attack Agent with M0 as the default
  progression and no Potential Awakening input. Retain level-60 base ATK 938,
  CRIT Rate 19.4%, and CRIT DMG 50% because the current general-damage Result
  consumes them. Her released faction has no matching admitted teammate and no
  current visible party consequence, so it is not retained for possible future
  use.
- R2. Add Knight's Extolment once as a limited S-Rank Attack W-Engine source
  fact. Shared equipment facts own Base ATK, advanced CRIT DMG, per-stack CRIT
  DMG, the two-stack Ice RES Ignore outcome, refinement progression, retained
  Basic/EX Special activation, duration, compressed Setup copy, and image. The
  Heavy Attack qualifier, per-action stack restriction, and refresh are checked
  at Agent authoring before candidate valuation. Every admitted Knight holder
  has both retained action-type routes and therefore reaches the same two-stack
  selected Result, so those source details do not justify a runtime Heavy-Attack
  capability model. Agent authoring stores no copied equipment values.
- R3. Completed Core supplies Fully Enabled CRIT Rate and Stun DMG Multiplier.
  Aerial Patrol Spear establishes Fully Enabled reachability, while the Stunned
  target condition is intrinsic to the Stun DMG Multiplier formula region; neither
  creates a separate action outcome. Retain the exact current numeric outcomes;
  omit activation duration, extension, resource, and raw skill coefficients from
  Result and Setup inputs.
- R4. Chain Attack supplies Converging Spear DMG and remains an exact action
  difference. The successful-block Daze increase does not enter Result because
  Sigrid's authored direction strengthens personal damage rather than Daze
  contribution. The block shield, Formation Breaker sequence, Decibels, action
  coefficients, and duration/cadence do not create normalized Result rows.
- R5. Additional Ability supplies self flat ATK only when another applied Agent
  is Support or Stun. Its Contamination-only DMG clause has no current enemy-state
  input or Result sink and is deferred until the Wind owner decision and the
  resulting current consumer exist. This vertical does not settle permanent
  omission of that clause. Sigrid's released faction does not replace this exact
  Specialty qualification.
- R6. M1 adds self ATK%. M2 adds PEN Ratio only to Unbridled Spear and Converging
  Spear. M4 adds broad DMG while Aerial Patrol Spear is active. M3/M5 skill levels,
  M6 extra coefficients and sequence changes, and duration extensions create no
  retained normalized Result. M6 remains Mindscape 6, not Potential Awakening.

## Testing Delta

- The new observable relationship is one general-damage profile that combines
  a qualifying flat stat with broad Core modifiers, a Basic form, and a collective
  source-local action modifier. The nearest Pyrois profile assertion proves a
  qualified stat and canonical Ultimate scope but cannot prove Converging DMG,
  M2 action-local PEN, or omission of an off-direction Daze clause. Add one
  representative calculation-flow assertion that binds the retained outcomes and
  omitted Daze row; it remains meaningful with equivalent renamed actions and
  values.
- Knight's stack maximum, Attribute gate, refinement progression, Setup
  compression, and ordinary projection use existing equipment mechanisms. The
  current shared equipment and lifecycle invariants already prove those
  mechanisms; extend exhaustive records for the new Engine rather than creating
  an item-specific suite.
- Received-Ultimate candidate admission already has shared coverage, but the
  nearest test does not compose party-draft isolation with SW-011 Party Apply
  rebuilding. Extend that shared flow once through Dialyn present, draft-absent,
  applied-absent, and reapplied-present states. Broad pre-PEN removal,
  pressure-safe preparation, zero-substat completeness, pool rebuilding, and
  incomplete Result introduce no new mechanism and retain their current shared
  coverage; do not add a separate Sigrid lifecycle suite.
