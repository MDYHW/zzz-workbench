# CRIT Representative Balance

## Summary

Apply the permanent finite-opportunity and CRIT-cap rules consistently to the
current crit-capable damage contributors. Candidate memberships remain bounded
authored choices. This correction changes only prepared 2-piece and Slot 4
balances where the complete pool package, Mindscape, or exact party
qualification materially changes fixed CRIT supply.

The visible prepared setup still begins with zero supplied substat hits. The
authoring check separately reserves eight CRIT Rate and eight CRIT DMG hits for
Agents that retain both, caps CRIT Rate formula value at 100%, preserves lower
defining thresholds, and keeps a materially useful CRIT-stability advantage.
It is not a runtime optimizer and does not react to the user's current counts.

## Requirements

- R1. Direct edits remain local and Result never feeds preparation. This
  representative balance is authored from the applicable current candidate
  memberships rather than owning or freezing them.
- R2. Author the current representatives as follows:

  | Agent / boundary | Full pool | Non-limited pool |
  | --- | --- | --- |
  | Yixuan M0 | Branch & Blade + CRIT Rate | Woodpecker + CRIT Rate |
  | Yixuan M1+ | Woodpecker + CRIT DMG | Branch & Blade + CRIT Rate |
  | Yidhari | Branch & Blade + CRIT Rate | Branch & Blade + CRIT Rate |
  | Evelyn | Woodpecker + CRIT DMG | Branch & Blade + CRIT Rate |
  | Corin | Branch & Blade + CRIT Rate | Woodpecker + CRIT Rate |

  Hugo's corresponding outcome is now owned by the
  [Hugo recovery vertical](2026-08-14-hugo-authority-recovery-requirements.md).
  Banyue and Starlight Billy are owned by their
  [Rupture recovery vertical](2026-08-14-banyue-starlight-billy-authority-recovery-requirements.md).
  Manato, Seed, and Cissia keep their existing representatives because their
  complete packages retain a distinct current balance or operation. Polar
  Metal's distinct Hugo comparison is owned by the Hugo vertical.
- R3. Anby's base M0-M6 representative is Woodpecker in both pools, with CRIT
  Rate Slot 4 in full and CRIT DMG Slot 4 in non-limited. At M2+, and only when
  another applied Stun or Support Agent qualifies her Additional Ability,
  authorized preparation uses Branch & Blade while preserving those pool Slot
  4 choices. An unqualified party keeps Woodpecker. Party Apply re-evaluates the
  authored context; a target-only Mindscape or pool change may read the
  established other party members and reprepare only Anby.
- R4. Evelyn's full zero-substat representative begins below the 80% threshold.
  Two CRIT Rate hits activate it; the conservative eight-hit opportunity still
  remains below 100%. Non-limited also begins below 80% and reaches it inside
  the same bounded opportunity. A defining threshold must remain reasonably
  reachable; it need not be pre-filled by fixed slots at zero.
- R5. Yixuan Mindscape transitions rebuild only the changed setup and resolve
  the corresponding row above. Returning to an earlier Mindscape authors that
  earlier representative anew with zero substat counts. Hugo's equivalent
  boundary is owned by his recovery vertical.
- R6. When no effective substats are currently offered, Setup keeps the compact
  Sub stats heading and empty grid. This is a complete zero-input scaffold, not
  an incomplete selection or a recommendation.

## Common Acceptance

- AE1. Shared preparation checks confirm each prepared 2-piece differs from the
  selected 4-piece and remains in the Agent's current candidates. Representative
  boundary cases cover the authored R2 consequences; R2 remains the owner of
  those values.
- AE2. Anby M0 qualified, M2 unqualified, M2 qualified, and both pools prove the
  shared party-specialty predicate and the exact prepared consequence. Her
  Additional Result uses the same predicate rather than a second named rule.
- AE3. A representative state lifecycle proves Yixuan M0/M1+ pool changes,
  zeroed substats, and target-only rebuild preservation.
- AE4. Evelyn at zero shows the inactive 80% gauge and no scale operation; two
  CRIT Rate hits activate ×1.25. Non-limited remains independently inactive at
  zero. This proves threshold reachability without inserting hidden hits.
- AE5. A high-CRIT setup crosses 100% and the visible Result clamps once with a
  reconciled cap adjustment; uncapped CRIT never appears as a user value.

## Exclusions

- No runtime score, damage simulator, farming-probability model, exact Disc-line
  feasibility validator, or automatic substat allocator.
- No candidate removal based on edited counts and no universal named-Agent
  representative table in production.
- No change to the zero-substat Setup layout beyond documenting its current
  complete empty scaffold.
