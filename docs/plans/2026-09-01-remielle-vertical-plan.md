# Remielle Vertical Plan

## Outcome

Add Remielle as one complete prepared Lumiflux Anomaly setup. Preserve her
declared Attribute while deriving only the current damage and Attribute-scoped
effect Attribute from the cyclic next applied Agent. Expose Refringe and
Luminize as distinct Result relationships, and show complete source-owned Ode
of Resurrected Wings and Feathered Fate packages in Setup.

The approved supporting requirement records the already-closed semantic
outcome. This plan does not validate that requirement or authorize a candidate
conclusion; it carries only the implementation and verification work that
follows from it.

## Units And Dependencies

1. **Semantic prerequisite (closed)** — `GV-011`, `SW-021`, `FM-012`, the exact
   contextual-Attribute and relationship consumers, nearest similar cases, and
   contrasts were rechecked before implementation. The approved requirement
   owns the Ode and Feathered source-first eligible-holder cohort,
   complete-package comparisons, finite opportunity, acquisition roles, and
   explicit existing-roster no-change outcomes.
2. **Content and shared relationships** — Add Remielle and shared equipment
   facts; extend only the existing contextual Attribute, materializer,
   relationship, preparation, and source-presentation paths. Keep source facts,
   Agent-local setup policy, and Result relationships in their existing owners.
3. **Setup compression** — Compare retained Ode and Feathered facts with their
   selected copy, Ode's reachable candidate accessible description, and the
   shared selected/candidate description path. Omit routine activation and
   duration while preserving recipient and affected Attribute Anomaly scope.
4. **Result and lifecycle** — Verify Refringe, Luminize, party delivery, ATK
   gauge, Mindscape, applied next-Agent Attribute, wraparound, draft isolation,
   pool/Mindscape rebuilding, direct edits, zero-substat initialization, and
   incomplete Result through existing shared flows.
5. **Visual acceptance** — Inspect the original portrait and compare Remielle
   expanded and compact at desktop and one narrow viewport in the in-app
   Browser at `127.0.0.1:5173`.
6. **Final verification** — Run focused behavior tests, the full root and
   governance suites, TypeScript/build verification, `git diff --check`, and a
   controller review of the final diff.

## Ownership

- Shared Agent and equipment facts remain in their current content owners.
- Remielle candidate and representative identities remain Agent-centered setup
  authoring.
- Formula and relationship changes remain in the current formula-policy and
  shared profile/materialization consumers.
- UI work is limited to the existing setup and Result surfaces plus portrait
  admission.

## Testing Delta

- The contextual Attribute test must prove selected Timeweaver remains selected
  after Party Apply before observing the changed next-Agent Attribute; otherwise
  representative rebuilding can create a false positive. Existing fixed-
  Attribute tests cannot prove this state transition or slot-3 wraparound.
- The Remielle ATK gauge test must prove count-sensitive current basis, output,
  cap composition, and delivered party contribution for two and three Anomaly
  Agents. Existing gauge tests do not prove this exact count-dependent provider.
- Ode and Feathered add no materialization mechanism. One shared source-copy
  assertion verifies that routine activation is absent while exact affected
  scope remains; existing selected/candidate accessible-description coverage
  proves both UI destinations reuse that copy. Feathered is Remielle's sole
  4-piece candidate, so it has no candidate selector state to duplicate.
- Candidate membership and representatives remain local authoring outcomes; do
  not add roster or exact-candidate catalogue tests.

## Non-Goals

- No damage simulator, Voidflare history, cadence model, Attribute graph,
  candidate registry, runtime optimizer, evidence payload, or item-specific
  calculator.
- No speculative Refringe propagation to Abloom, Vortex, Luminize, or another
  source-local anomaly outcome.
- No unrelated Agent, equipment, visual-layout, or lifecycle refactor.
