# Norma Hollowell Vertical Implementation Plan

## Outcome

Admit Norma and Chief Sidekick through the established setup and Result
experience, including the one new bounded Sheer Force-to-ATK relationship,
without changing another Agent's authored setup meaning.

## Units

1. **Shared source content**
   - Add Norma identity, base inputs, source labels, Chief Sidekick facts,
     compressed copy, and original assets.
   - Verify Chief uses only the generic equipment materializer and that selected
     and candidate Setup descriptions expose the same source-owned package.
2. **Completed-metric conversion**
   - Add one relationship that reads a completed delivered metric at Fully
     Enabled and emits one self stat plus a visible gauge.
   - Keep the pass one-way: no provider, callback, recursion, or new formula
     family.
3. **Agent setup and Result**
   - Add the settled candidate, representative, Disc, main-stat, substat,
     formula, profile, Core, Additional, and Mindscape authoring from the Norma
     requirement.
   - Preserve M0 default, static candidates, selected-input lifecycle, and
     unaffected existing profiles.
4. **Behavior verification**
   - Extend shared reference-integrity and source-fact checks only as required by
     the new identities.
   - Add one generic calculation-harness test for delivered metric → self stat
     and gauge. Nearest coverage is the post-delivery stat-basis test; it cannot
     prove a delivered modifier metric becomes a stat without becoming a
     `StatId`.
   - Add one Norma/Lucia integration journey because source wiring and the
     presence/absence party transition are the materially distinct visible
     failure. Existing lifecycle suites cover ordinary pool rebuild, invalid
     clearing, zero initialization, and incomplete Result, so do not duplicate
     them per Agent.
5. **Visual and final verification**
   - Run focused tests, root tests, governance checks, type check, production
     build, and `git diff --check`.
   - Inspect the original portrait and compare Norma at `127.0.0.1:5173` on
     desktop and one narrow viewport, expanded and compact, including adjacent
     compact context and overflow.
   - Review the final diff against the requirement and close this plan only
     after the committed implementation preserves its detailed history.
